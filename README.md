# WordPress AI Poster

Автоматическая публикация постов на WordPress через OpenRouter AI.

## Требования

- Python 3.10 или выше → https://www.python.org/downloads/
  - При установке поставь галочку **"Add Python to PATH"**

---

## Установка и запуск

### 1. Установить зависимости

Открой папку с проектом в командной строке и выполни:

```
pip install -r requirements.txt
```

### 2. Запустить приложение

```
python main.py
```

---

## Быстрый старт

### Вкладка "Настройки"

**WordPress сайты** — вводи в формате одна строка = один сайт:
```
https://example.invalid:YOUR_USERNAME:YOUR_WORDPRESS_PASSWORD
https://second.example.invalid:YOUR_USERNAME:YOUR_WORDPRESS_PASSWORD
```

**OpenRouter AI:**
1. Вставь API Key с https://openrouter.ai/keys
2. Модели подгрузятся автоматически — выбери нужную
3. Нажми "Сохранить настройки"

---

### Вкладка "Категории и теги"

- Вводи категории и теги по одному на строку
- Укажи сколько выбирать случайно на каждый пост
- Можно включить автогенерацию **TOC (содержания)**

---

### Вкладка "Генерация и публикация"

1. Напиши промт для контента
2. Опционально — промт для заголовка (поддерживает `{content}`)
3. Используй переменные в промте: `{тема}`, `{город}` и т.д.
4. Нажми **"🔍 Найти в промте"** чтобы появились поля для переменных
5. Нажми **"▶ Начать публикацию"**

**Кнопка "🧪 Тест"** — публикует черновик без AI, чтобы проверить подключение.

**Сохранённые промты** — сохраняй промты по названию и переключайся между ними.

При первом запуске автоматически загружаются примеры из `config.example.json`:
статья о домашнем рабочем месте и статья на свою тему. Для второго примера выбери
«Пример: статья на свою тему», нажми «Загрузить» и заполни поле `{тема}`,
например «уход за комнатными растениями». Промт заголовка использует `{content}` —
приложение подставит туда сгенерированный текст статьи.

---

### Вкладка "Проверка XML-RPC"

Вставь список доменов в любом формате — домены извлекутся автоматически.
Нажми **"▶ Проверить"** — скрипт проверит каждый домен на доступность XML-RPC.
Рабочие домены можно скопировать или сохранить в файл.

---

## Результаты

После публикации ссылки на посты сохраняются в файл `results.txt` (в папке проекта).

---

## Файлы проекта

| Файл | Назначение |
|---|---|
| `main.py` | Точка входа |
| `app.py` | Интерфейс |
| `worker.py` | Поток публикации |
| `openrouter.py` | Клиент OpenRouter API |
| `wordpress.py` | Клиент WordPress XML-RPC |
| `config.py` | Настройки и утилиты |
| `config.json` | Сохранённые настройки (создаётся автоматически) |
| `config.example.json` | Шаблон настроек с примерами промтов без личных данных |
| `results.txt` | Ссылки на опубликованные посты |

Ключ OpenRouter, логины и пароли WordPress вводятся пользователем во вкладке
«Настройки». Для первого запуска файл `config.json` не нужен: пока его нет,
приложение читает `config.example.json`. При сохранении настроек создаётся локальный
`config.json`; при следующих запусках используются уже ваши настройки.
Не добавляйте личные данные в `config.example.json`.

Приложение сохраняет настройки, включая ключи и пароли, в `config.json` в открытом
виде. Этот файл, результаты публикаций `results.txt`, экспорт `xmlrpc_ok.txt`,
логи, локальные архивы и Python-кэш исключены из Git через `.gitignore`.
